# Team Creation Website To Choose Your IPL-Team

## About My Project 

A simple and user-friendly project that helps you choose and organize the Players for your next Tournament. Easily add the Players you want to Add or remove one Player, and rearrange them to create your desired Team.

Have a Look to my website [Live LInk](https://ipl-dream.netlify.app/)

## 🛠️ Technologies Used

  - React.js
  - Tailwind CSS
  - TypeScript (ES6+)
  - React-Toastify (NPM Package)
  - JSON (for technology data)
  - Vite (build tool)

## ✨ Features

1. Easily add your desired Players.
2. Remove any Player if you change your mind.
3. Get clear and easy-to-understand notifications when adding or removing Players.
